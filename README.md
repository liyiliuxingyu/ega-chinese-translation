## 核验与构建

从仓库根目录核验此次公开快照的全部文件载荷，包括原续作包和新增 Dot 资料：

```bash
python3 tools/verify_repository.py --strict
```

根层核验入口 [tools/verify_repository.py](tools/verify_repository.py) 要求 **Python 3.11 或更新版本**。它检查文件完整性，不能替代数学核查。原续作包还保留自己的独立清单与核验入口：

```bash
python3 archive_20261121/verify_package.py --strict
```

这一命令只核验 `archive_20261121/` 中清单所列文件的安全路径、大小和散列；新增 Dot 资料另查其索引。它不检验译文正确性。

原包应保持原样。需要实际构建或编辑时，先复制到一个尚不存在的工作目录，再调用包内入口：

```bash
python3 -c 'from shutil import copytree; copytree("archive_20261121", "../ega-work")'
bash ../ega-work/BUILD_ALL.sh
python3 ../ega-work/01_project/EGA_v17/checks/check_current_project.py
```

`copytree` 遇到已有目标目录会失败，不会覆盖已有工作。这里的 `../ega-work` 是示例路径，可换成新的工作目录。构建使用的真实入口是 [BUILD_ALL.sh](archive_20261121/BUILD_ALL.sh)，其内部调用 [build.sh --verify-single](archive_20261121/01_project/EGA_v17/build.sh)，生成主稿、报告及两个单文件源码的 PDF，并运行日志检查和模块／单文件逐页比对。它只构建所复制的已有合订工程，**不会自动导入新增 40 批**。

构建需要 Bash、Python 3、XeLaTeX 及所需 TeX 宏包和字体，逐页比较另需 PyMuPDF。旧包自身的校验、恢复工具要求 Python 3.9 或更新版本；上述仓库根层校验工具要求 Python 3.11 或更新版本。工程带有既有 CTeX 宏包、默认 Fandol 字体及许可文件，没有附带完整的跨平台 TeX 发行版。环境仍应按[工程说明](archive_20261121/01_project/EGA_v17/README.md)检查。合订主工程采用真实 `ctexbook` 默认设置；独立 Dot 批次按收到时的原版式保存，整合时需要统一。

包内 `checks/current_*` 与[2026-11-21 核查摘要](archive_20261121/00_START_HERE/工程核查摘要.md)是当时的证据记录。本次公开归档不把这些历史记录改称新的构建结果。修改源码后，应记录实际差异、重新检查与渲染，再更新接续状态和清单；单纯刷新散列不能代替检查。

## 恢复旧工程

当前模块工程已经展开，正常续作不需要先恢复历史。如需重现特定旧版的普通文件：

```bash
python3 archive_20261121/restore_versions.py --list
python3 archive_20261121/restore_versions.py --version v17 --destination ../ega-v17-restored
```

目标须为新目录或空目录。索引另列 `supplement_III`、`supplement_III_delta`。脚本按索引复制并重新核对每个普通文件的路径与字节，不能据此重建原 ZIP 容器本身的相同字节。使用边界见[历史恢复工具说明](archive_20261121/00_START_HERE/历史恢复工具说明.md)。
