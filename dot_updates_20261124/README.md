## 接续时读哪一处

第86批实际主源码收录英译底本物理112页的 1965 年 9 月 29 日信件，对应法文物理148–149页，并把被划销的技术段落单列。第87批另处理法150页的手写提纲和法153页的异扫同文。

### 最近的法文回校

第108批主 TeX 实际收录：法物理45页命题8.13标题，至法46页8.14引句之前，含经译校陈述、证明、划改记录，以及明确分列的现代补证和例子。

下一锚点是：

> 法文物理46页底部 “Combinant 8.13”／“Corollaire 8.14”，承法47页；对读英译物理32页。

旧档案 old008 及后续包已经收录8.14之后的译文。因此这是**回校接续点**，不能删掉既有后段，也不能把它误报为整个工程的最新译文终点。

仍须保留的未决项包括：

- 8.7(c)在法40／41页和英28页之间的缺续尚未复原；没有证据证明是整页缺失，不能自行补造。

- 法45–46页若干边注不清；8.14及以后尚需按当前法文回校路线推进。
- 法150页部分缩写、反向划销字迹及法153页边缘痕迹未全部辨清。
- 法文全171页的内容审计尚未闭合。正式出版 EGA 各卷也不因这些预备笔记包而宣布完成。

每批原 PROGRESS 中的“下一项”是该批交付时的历史断点，许多已由后批推进。索引同时保存历史原件和当前归档判断，以免把旧断点当成当前缺漏。

## 源码、引用副本与编译

每包都有同名主 TeX 和 PDF，并保留原 build.sh、verify.py、PROGRESS.json、README.txt、SHA256SUMS.txt。第108批原 ZIP 没有 AUDIT.txt；本轮没有伪造一份原校记。其现存译注、README 和进度文件仍保留。

63 个 TeX 文件的角色不同：

- 40 个是各包的主文档。
- 第88–90批内的3份“基线_v5_01_02.tex”与旧工程同名正文逐字节相同。
- 第91–108批内的18份“基线_v5_03_06.tex”与旧工程同名正文逐字节相同。
- 第106批引用的前批105源码、第107批引用的前批106源码，与对应前包主 TeX 逐字节相同。

后23份是参考副本，不是额外23批，也不是这些包的编译入口。主 TeX 没有外部 input/include/includegraphics 依赖；它仍需要系统可用的 XeLaTeX、CTeX、Fandol 以及文件所列宏包。这里没有携带完整 TeX Live。

原包采用 ctexbook，显式设置 openany、fontset=fandol，并有 geometry 等排版设置。本轮保持原字节，没有把它们宣称为新统一的 ctexbook 默认版式。以后合订时应按统一排版要求处理，同时保留原始档案供比较。

如要重编某一包，可进入该包目录运行原 build.sh；本次归档没有执行它。第107、108批的 verify_examples.py 另需 SymPy；原 verify.py 只用 Python 标准库。原脚本、原 PDF 以及原报告中的编译或审校表述，属于历史工程记录，不是本轮重新完成的验证。

## 本轮实际核验

本轮执行了：

- 40 个 ZIP 的 CRC、安全相对路径、归一化重名、加密成员及符号链接检查。
- 全部492个成员的完整解包与字节核对。
- 全部452条原 SHA256SUMS 记录的校验。
- 40份实际主 TeX 的标题、条目范围、末尾正文与接续锚点读取。
- 旧75条主源码的实际哈希复核，以及上述23份引用 TeX 的来源匹配。
- 40份既有主 PDF 的可打开性、页数及中文文本可提取检查；合计199页，仍是40份独立 PDF，不是新合订本。
- 另84份源文件／摘页 PDF 与完整底本的逐页组件身份匹配。方法是按序嵌入图像的 SHA256 及标准化抽取文本匹配，不等同重新目视核验版面，也不证明数学正确。详细页序见 SOURCE_PDF_IDENTITY.json。部分包附完整英文底本，其余为摘页；应以该表的角色和实测页数为准。

原始 ZIP 共29,406,203字节；解包成员共31,516,025字节。本轮没有逐页渲染审校、重新编译或重审全部数学证明。

从任意工作目录均可用 Python 3 标准库重跑本轮核心档案检查：

~~~sh
python3 dot_updates_20261124/verify_archive.py
~~~

脚本只读原 ZIP、索引和解包文件，不执行档案中的任何代码。若需写一份新的检查结果，可使用 --report 指定另外的路径。当前随附 ARCHIVE_VERIFY.json 是本轮实际运行的结果；后续修改索引或成员后，应重新检查并保留新的记录。

## 继续工作的方法

先读仓库根的接续说明与本索引，选择“新增后续合并”或“法文回校”这一具体任务。用 INDEX.json 指明的主 TeX、原底本页序和旧段映射实际核对，再在工作副本中修改。原批主文、现代译注、作者划销文字和未决缺文的身份应保持可追溯。

不要把40个文档拼接成一个假定无重复的正文；不要仅凭文件名、README状态或较新的批号认定全文完成。统一合订的最终目录、条目连续性、数学更正、编译和页面检查，仍是后续独立工作。
