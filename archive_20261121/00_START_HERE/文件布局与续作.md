# 文件布局与续作

| 路径 | 用途 |
|---|---|
| 01_project/EGA_v17/ | 当前可以直接编辑和编译的工程；包含实际PDF、单文件TeX、模块、脚注及累计报告 |
| 03_sources/ | 13份底本原件；保留PDF与PS原格式 |
| 05_Dot/batches/、original_archives/ | 从旧完整包恢复的56批原稿与3个原始Dot归档 |
| 05_Dot/new_20261121/ | 新19批的原ZIP与分批展开的源码、进度、审校和脚本 |

| 04_history/RESTORE_INDEX.json | 三个旧输入包逐普通文件恢复映射 |
| 04_history/content/ | 未在当前可读目录中重复保存的历史字节载荷，按SHA-256定位 |

| verify_package.py | 只读核验本包 |
| restore_versions.py | 向新的空目录按原路径还原指定历史工程 |
| refresh_manifest.py | 修改工程并核验后刷新文件清单；刷新本身不证明修改正确 |

新Dot批次中的PDF和法文摘页没有丢弃，完整原件仍在各自ZIP中；为了避免重复体积，仅另展开其文本、进度和代码。不同批次同名README、PROGRESS和build.sh各在独立目录，不能平铺互相覆盖。

历史版本按需恢复；本包当前工程已展开。当前126份TeX源文件保持第三辑收到时的数学内容，本轮重写的是接续与工程文档。若后续改稿，应在保留旧快照后更新来源记录、独立展开、实际构建与检查结果，并刷新清单。

从封面起数的译本物理页码、底本物理页码和原书印刷页码是三套不同编号。任何续译开始前，都要同时查到实际条目与底本原文。

## 后续改稿时的历史保护

历史版本所引用的现行TeX、源码和构建文件已另外按SHA保存不可变快照；后续修改工作稿不会改写这些历史字节。03_sources、05_Dot原始归档、vendor及明确的history目录仍作为共享原件，须保持不变；如需处理，请在另一个副本上操作。
