# 本轮整合证据与执行范围

本目录记录2026-11-21的实际恢复、源码包含、接续与页图检查。原始审计文件保留执行当时的路径和当时阶段的清单散列；这些路径不是新对话必须依赖的工作目录。

当前可移植运行入口在包根verify_package.py、restore_versions.py和01_project/EGA_v17/build.sh及checks/check_current_*.py。这里的组包配方及原只读审计脚本保留当时输入目录和旧外层ZIP路径，属于过程证据；不要当成现行一键构建脚本。

原批次数学核查自述仅作为出处保留。此次独立核查主要确认CRC/SHA、源稿字节、正文完整包含一次、底本页身份、实际接续点、编译及明确列出的页图；没有把这些技术结果升级为全书数学证明认证。

final_preservation_check记录首次实际恢复；immutable_restore_check记录随后加强不可变源码快照后的再恢复。最后交付ZIP的外层CRC、SHA和解包复验记录随交付文件单列，避免让ZIP自我包含自己的散列。
