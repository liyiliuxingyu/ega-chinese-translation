# 代数几何基础：内容顺序合订本（第七版）

本工程包含当前已译范围的中文合订本及累计译校报告。具体完成范围和下一接续点以 `PROGRESS.md` 为准。下一处为第0章19.7章首及19.7.1；不能把本工程称为全部EGA卷册的完结全译。

## 编译

需要安装XeLaTeX、CTeX、amsmath、tikz-cd、hyperref等常见TeX Live宏包。

- 分文件工程：执行 `bash build.sh`，得到 `main.pdf` 与 `report.pdf`。
- 同时验证单文件：执行 `bash build.sh --verify-single`。
- 独立源码：`single.tex` 和 `report_single.tex` 不依赖原文扫描图，可分别用XeLaTeX连续编译三遍。
- `flatten_sources.py` 只展开工程内的input文件，不修改数学内容。

本版保留ctexbook默认中文字体、字号、版心、页眉与双面分页。默认生成的空白偶数页不删除。封面及总目录重新编译，不是PDF拼接。

## 校订

正文采用已经核实的修订，脚注记录原文差异及依据；较长反例和补证见报告。旧正文的回溯修改仅限PROGRESS列明的条目。报告中的历史章节保留当时判断，不自动视为本轮重新审定。

本版合订本918页，累计报告141页。编译、结构保留、逐页比较与渲染检查记录位于 `checks/`；历史记录位于 `history/`，不得误认作本轮新验证。

工程不含字体文件。PDF中的字体仅按TeX正常方式嵌入；没有提供或分发独立字体资源。
