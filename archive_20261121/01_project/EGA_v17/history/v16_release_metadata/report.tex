\head{报告说明}
本报告包含本轮第0章§23的新核查，以及此前各轮历史记录。
本轮止于（23.2.10，ii）末尾，新标识为P16。
正文采用校订后的陈述，原写法与依据放在脚注；详细反例和补证列在报告。
重点是有限中间环的半局部性、整性越过幂零根的提升，以及应用中的完备性和局部化步骤。

历史报告保留当时编号和措辞，不表示本轮重新审定其全部结论。旧版H8-P01等待核事项继续保留。
