## 编译

使用带中文支持的TeX Live或MiKTeX、XeLaTeX及常用宏包（ctex、amsmath、mathrsfs、tikz-cd、longtable、hyperref等）。字体由CTeX在当前平台的默认配置决定，工程包不含字体文件。

在工程目录运行：

```sh
bash build.sh
```

将独立源码也重新编译并比较时：

```sh
bash build.sh --verify-single
python3 checks/compare_outputs.py
```

或对单文件源码直接连续编译三次：

```sh
xelatex -interaction=nonstopmode -halt-on-error single.tex
xelatex -interaction=nonstopmode -halt-on-error single.tex
xelatex -interaction=nonstopmode -halt-on-error single.tex
```

单文件生成器为`flatten_sources.py`，从相同分文件工程展开`\input`，禁止递归输入及工程目录外输入。

`ctexbook`采用A4及默认字号、版心、标题、页眉和双面章节起页方式；只为保持原著编号调整章号与节号，不引入geometry、fancyhdr或自行指定字体。不同系统的默认字体/TeX版本可能改变分页；本次逐页一致性只指同一环境、同一渲染器下两种源码生成结果。
