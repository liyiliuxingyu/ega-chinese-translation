# 模块版与单文件版三页差异诊断

## 结论

高度确定的原因是旧单文件展开器在每个输入边界人为插入空行，使TeX收到新增的段落结束标记。差异三页恰对应104、105、106模块末尾。未发现数学内容改变；修复应放在展开器，保持模块正文不动。是否完全解决须由重建后的全页比对确认。

- 修复前 `single_build/book_single.pdf`：1210页，SHA256 `dafb8b32a45c8f031f17283bf831e4ae7b5967f42b5b451b0b215320b8a47dde`。

旧展开器替换的是`\input{...}`这个token片段，同时保留父文件原换行，却在BEGIN/END注释前后另添换行。因此，在`\endgroup`后形成原模块读取方式没有的空行。104末尾显示公式、105的(c)末段、106最后一段正是受影响的三处。

## 建议的精确修复

以整行匹配并连同原换行一起替换；BEGIN/END只作注释行，不另造空行；保留child原有全部空行，仅在没有末尾换行时补一个。不要用`rstrip()`删除原正文的空行。遇到内联或其他不支持语法直接报错。随后只需重新展开并构建两个单文件，再全页比较；不改数学正文。
