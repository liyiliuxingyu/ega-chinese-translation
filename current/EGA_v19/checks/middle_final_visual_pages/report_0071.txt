两个译校检验（非原文）
一、维数上界不能读作n −1。
取特征零代数闭域上的光滑二次曲面
X = {x0x3 −x1x2 = 0} ⊂P3,
n = 1.
把X 写成秩一的2 × 2 矩阵的射影簇。梯度给出由可逆线性变换诱导的对
偶点，故切平面参数的像是对偶空间中的二次曲面，余维为一。在点[1 : 0 :
0 : 0] 的切平面x3 = 0 上，截面方程为x1x2 = 0，两条不同直线相交。左右
换基可把任意秩一矩阵送到该点，所以每个切平面截面都有此类交点，交点
是曲线上的余维一点，其局部环不正则。这意味着Z1 包含对偶二次曲面。
若按英编稿读成“维数不超过n −1”，本例中此假设为空，但结论不成立。
法稿的n + 1 则会检验这个二维分支，并排除此例。
